# Fino, la mascota de Chollo Fino

Etiqueta de precio verde menta con pajarita verde oscuro. Se creó una sola vez con Higgsfield (Nano Banana Pro) el 9 de noviembre de 2026. No se vuelve a generar: los vídeos usan siempre estos archivos.

| Archivo | Postura | Para qué |
|---|---|---|
| fino-0-base.png | De frente, boca cerrada | Reposo; con fino-7 sirve para que «hable» |
| fino-1-saludo.png | Saludando | Inicio del vídeo |
| fino-2-sorpresa.png | Sorprendido, manos en la cara | Al revelar el precio |
| fino-3-senala.png | Señalando arriba | Señalar un texto o el precio |
| fino-4-pulgar-guino.png | Pulgar arriba y guiño | «Este sí merece la pena» |
| fino-5-celebra.png | Saltando con los brazos arriba | Final o chollo muy bueno |
| fino-6-piensa.png | Pensando | «¿Lo vale?» |
| fino-7-habla.png | De frente, boca abierta | Alternar con la base para hablar |
| fino-8-lupa.png | Con lupa | «Cazando chollos» |

Todos son PNG con fondo transparente. Colores de la marca: verde oscuro #0F3D2E y menta #7EE2A8. Sin texto en la mascota: el texto se añade aparte.
